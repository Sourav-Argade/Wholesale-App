Wholesale App

Route & Customer Manager — track customers, products, routes, and daily visits from your phone or laptop. Built for wholesale businesses, not spreadsheets.

Backend Offline — Preview Mode

✨ Everything You Need

👥

Customer Management

Add, edit, and search customers. Store shop names, phone numbers, GPS location, and notes. Pin your current location when standing at the shop.

📦

Products & Pricing

Maintain a product list with units and default prices. Set per-customer rates that keep a full history — never overwrite an old rate.

🛣️

Routes & Map View

Group customers into routes in visit order. View all your shops on an interactive OpenStreetMap, color-coded by route — no API key needed.

✅

Daily Check-in

Log which customers you visited today with GPS proof. Build a visit history so you always know when you last stopped by.

💰

Price History

See every rate you've quoted each customer per product, with dates. Always know the latest agreed price at a glance before you sell.

📋

Excel Backup

Export all your data to an Excel file anytime for backup or offline sharing. Import customers from an existing spreadsheet too.

🔐

Multi-User Access

Simple username/password login for you and 2-3 partners. Admin (full control) and Partner (view + check-in) roles included.

🗺️

GPS Location Pinning

Use your phone browser's Geolocation API to pin a customer's shop location when you're standing right there. No external GPS device needed.

🔍

Search & Filter

Quickly find customers by name or shop. Filter routes to see who you'll visit and their latest rates before heading out.

🛠️ Tech Stack

Java 17 Spring Boot 3 Spring Security H2 Database JPA / Hibernate Apache POI Leaflet.js OpenStreetMap Mobile-first CSS REST API

🚀 Run It on Your Laptop

The app runs 100% locally. Your partners connect from their phones over Wi-Fi. No cloud, no API keys, no monthly fees.

1
Install Java 17+ & Maven Download from adoptium.net or use your package manager
2
Clone the repository git clone https://github.com/Sourav-Argade/Wholesale-App.git
3
Start the app cd Wholesale-App && mvn spring-boot:run
4
Open in browser http://localhost:8080 Login with admin / admin123
5
Partners connect from phones On the same Wi-Fi, open http://YOUR_LAPTOP_IP:8080
